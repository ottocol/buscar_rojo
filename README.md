# buscar_rojo

Paquete de ejemplo de los apuntes `apuntes-fsm-bt.md`: el robot deambula hasta ver un
objeto rojo, le hace una foto y navega a un punto del mapa. La misma tarea se coordina
con una máquina de estados (YASMIN 6.x, `fsm_yasmin.py`) y con un behavior tree
(py_trees_ros 2.6, `bt_pytrees.py`). Ver la sección 6 de los apuntes para ejecutarlo.
